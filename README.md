# VibeLink Social App

A complete social media assignment built with React + Vite and Route Academy's Route Posts API.

## Required assignment features

- Sign-up page
- Login page
- Home page with all posts
- Post details with all comments
- Profile page
- Create / update / delete posts
- Create / update / delete comments
- Change user password

## Extras

- Responsive original UI
- Profile photo upload
- Post likes
- Optional image upload when creating or editing posts
- Pagination / load-more
- Toast notifications
- Protected routes
- Favicon included

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

API: `https://route-posts.routemisr.com`
